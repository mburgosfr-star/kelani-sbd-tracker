## What's new

- Kelani SBD Tracker now uses a new Android app identity and signing identity. This security migration means version 2.0.0 installs alongside the previous app instead of updating it in place.
- Existing users should first export a backup from the previous app, install version 2.0.0, and import that backup during the first-run setup.
- Keep the previous app installed until the imported training history, personal records, settings, and any in-progress workout have been checked in version 2.0.0.
