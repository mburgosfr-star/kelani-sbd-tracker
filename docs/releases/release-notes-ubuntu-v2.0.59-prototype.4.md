## What's new

- First experimental Ubuntu desktop package for Kelani SBD Tracker.
- Plan and log Squat, Bench Press and Deadlift workouts offline, with the same training engine as Android.
- Keep a separate desktop profile, automatic local backups and manual JSON export/import.
- Receive desktop rest-timer notifications and one short sound, including when the window is minimized.
- Return to the workout with the ready-for-next-set message still visible.

## Before installing

This is a test release for Ubuntu 24.04 or newer on amd64 computers. It is not a stable app-store release. Keep an independent JSON backup of your training data.

Download the DEB and its SHA-256 file. Follow the [Ubuntu guide](https://github.com/mburgosfr-star/kelani-sbd-tracker/blob/ubuntu-v2.0.59-prototype.4/docs/ubuntu-prototype.md) for installation, updates, backup locations and limitations.

The desktop profile is separate from Android. Import replaces the desktop profile; it does not merge histories or synchronize with your phone. Android calendar synchronization, automatic desktop updates and purchases are not available.

Keep the app running for rest-timer notifications. Closing the window quits the app. Sound follows your system audio output and volume. Ubuntu may suppress notification banners. On GNOME, an app pinned to the dock may no longer appear in the applications grid.

Report problems through [GitHub Issues](https://github.com/mburgosfr-star/kelani-sbd-tracker/issues). Do not post personal training backups publicly.
